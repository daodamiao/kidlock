遥控器使用说明

这里提供 上 / 下 / 左 / 右 / 确认(OK) / 返回 / 音量− / 音量＋ 共 8 个按键，点击后等同于按电视遥控器。

音量键直接调用系统音量服务，不需要注入权限，在任意界面都生效。其余按键优先交给盒子自带的系统遥控服务（8080 端口），由系统身份执行，因此方向键、OK、返回在第三方应用界面里也能生效。

所有按键都需要管理密码，首次打开时验证一次即可，本次浏览会话内有效。密码错误或已修改时会自动要求重新输入。

盒子的全屏锁屏页或家长验证页显示时，按键会直接送到该页面，也可以用来输入解锁序列。

为什么以前返回键会失效：普通应用没有系统注入权限（INJECT_EVENTS），adb shell 手动注入能成功是因为它跑在 shell UID。现在改为复用 N1 / YYF 盒子系统的 POST /v1/keyevent 接口（与手机端「N1 遥控器」App 完全一样，只是从本机 127.0.0.1 走），按键由盒子系统服务执行。若盒子上没有这个服务，会依次回退到 root 身份执行 input keyevent、以及无障碍全局返回（点页面「去开启」，在「设置→无障碍」打开「儿童限时管控」）；该服务不读取屏幕内容。

页面顶部状态条显示 8080 系统遥控服务是否可用，服务后启动时点「重新检测」即可。发送成功后状态栏会显示实际生效的路径（如「盒子系统遥控服务 :8080/v1/keyevent」「应用内投递」「root input keyevent」「无障碍全局返回」「系统音量服务」）。若提示「发送失败」，后面会带上每条路径的具体原因。
